# 儿童 AI 素养课程内测｜监护人意向回复卡（内部）

本卡只用于公众号私信的人工回复，不自动读取私信，不复制账号、昵称或消息原文。公开招募仍按 `intake_only` 执行：登记不等于录取，不收费。

若私信带有已配置来源码，只把它计入聚合来源分布：`儿童AI内测-星球 / -公众号 / -X / -CSDN / -头条 / -网站`。基础关键词 `儿童AI内测` 或无法确认来源时记为 `unattributed`；不得依据账号、发信时间或措辞猜测来源。

## 三个最小字段

- 年龄段：8—10 / 11—12 / 13—14；
- 每周共同投入：少于 30 分钟 / 30—60 分钟 / 60—90 分钟；
- 参与偏好：异步任务 / 集中答疑 / 两者都可。

三个字段齐全且由监护人表达，才计一条 `newQualified`。不要求孩子姓名、学校、位置、账号、正脸、声音、聊天、健康情况或原始作品。

## 回复分支

### 三项齐全

已收到这三项监护人意向。当前只是适配登记，不代表录取，也不进入付款。完整的时间、交付、支持和退出边界确认后，我会再单独说明；这期间请不要补充孩子姓名、学校、照片、聊天或作品。

三项齐全只增加有效意向，不自动发送试学邀请。作者确认本批可以承接免费研究型试学后，才使用 `course-beta-free-trial-start-and-progress-card.md` 单独说明参与、暂停和退出边界，并取得监护人明确参与选择。之后完成一项新的指定课程任务才计课程开始；既有作业、公开试听播放、阅读或点赞都不能倒推为开始。

### 缺一项

还缺“【年龄段 / 每周共同投入 / 参与偏好】”这一项。只补这一项即可，不需要介绍孩子身份、学校、具体位置或学习经历。

### 每周少于 30 分钟

已记录。四周内测需要监护人共同参与，少于 30 分钟可能更适合先看公开材料或参加知识星球的单次任务。这里不把时间不足解释成孩子能力问题，也不推动付款。

### 询问价格或付款

当前只登记意向，付款尚未开放。价格、周期、家庭上限、退款、支付方式、支持响应和合规门禁未全部确认前，不收款，也不接受个人转账或收款码。

### 想提交作品或聊天作为证明

这一步不接收孩子姓名、学校、照片、声音、聊天或原始作品。只保留年龄段、共同投入时间和参与偏好即可；作品表现不会决定登记或后续付费资格。

### 出现儿童隐私内容

不复制、不截图、不写入本地台账，不继续追问。暂停该条自动处理并告知作者，由作者在公众号可见界面决定请监护人撤回、删除或改写。去标识化前不计入意向或案例。

### 医疗、心理、法律、财务或紧急安全问题

这套课程不提供医疗、心理、法律、财务或紧急安全建议。请联系能承担责任的监护人、学校或相应专业机构；不把聊天机器人作为真人支持替代。

## 聚合记录

每次人工处理后，只记录以下数字：

- 本次核验私信数；
- 新增有效意向；
- 缺字段；
- 重复；
- 不适配或主动放弃；
- 已有有效意向中的撤回数；
- 新增有效意向的年龄段、共同投入和参与偏好分布。
- 新增有效意向的来源分布：知识星球、公众号、X、CSDN、今日头条、网站、未归因。

不得记录昵称、账号、消息原文、自由文本问题、联系方式或任何儿童资料。年龄段、共同投入、参与偏好和来源四组分布各自之和必须等于新增有效意向；活动有效意向为“上一快照有效意向 + 本次新增 − 本次撤回”。
