## 知识星球

### 标题

L08｜AI 可以写报告，但不能替孩子补出一次实验

### 正文

今天把 L04—L07 合在一起：定义问题、拆步骤、安排人机分工、核验证据，然后完成一次低风险亲子研究的第一轮试验。

示例问题是：“同样一张纸，用不同结构跨过同样宽度，哪种能稳定承受更多相同硬币？”

AI 可以协助：提出结构候选、检查方法缺口、生成空白记录表、根据真实数据给出比较草稿。

人必须完成：确认安全、实际操作、观察和记录、解释异常、检查计算、决定采用与拒绝，并对最终结论负责。

最重要的规则：AI 不能补写没有做过的实验数据。没有记录就写“未记录”或重新试验，不要让一串看起来合理的数字填满表格。

请提交去标识化的研究日志第一版：

1. 一个低风险、可以观察的问题
2. 主要改变的条件和保持一致的条件
3. 人机分工
4. 一轮逐次原始记录与异常
5. 采用、拒绝或修改了哪些 AI 建议
6. 暂时结论、至少两个局限和下一步

今天只做一轮试验，不比作品是否漂亮。不要提交姓名、学校、住址、精确位置、正脸、账号、联系方式、私人聊天或带身份信息的照片。涉及明火、药品、电器拆解、高处、道路、身体实验或高影响建议的问题不进入儿童任务。

## CSDN

### 标题

用 AI 做研究时，先保护原始数据：一条面向家庭项目的可追溯流水线

### 技术角度

- 将 problem、hypothesis、method、raw observations、derived analysis 与 conclusion 分层存放
- 原始记录 append-only；模型只能生成 derived artifact，不能回写或补齐观测值
- 为每次提示记录 candidate output、accepted change、rejected change 与 human owner
- 方法变更保存 reason 与时间顺序，避免用最终方法伪装整个过程
- 将 anomaly 与 missing value 保留为一等状态，不把“未记录”转换为 0
- 结论绑定 experiment scope、limitations 与 reproducibility checklist

### 示例结构

```text
question -> method v1 -> pilot observation
        -> method change + reason
        -> raw records (immutable)
        -> AI-assisted derived analysis
        -> human-checked conclusion + limitations
```
