你手里只有一个模型时，环境变量怎么写都不算麻烦。等到 Claude、国产模型、代理接口和测试账号全塞进来，事情就变了：今天改这个配置，明天忘了上一次用的是哪个地址，最糟的是密钥还散落在几个文件里。

cc-switch 解决的就是这类小麻烦。它把不同 AI CLI 的供应商配置放到一个图形界面里，让你看得到当前选中项，也能更快切换。

![cc-switch 配置管理界面](/images/blog/cc-switch-introduction-install-guide/dashboard.webp)

## 它不是另一个模型客户端

cc-switch 不提供模型额度，也不会替你申请账号。它管理的是本地工具读取的配置，例如接口地址、模型供应商和必要参数。你原来用 Claude Code、Codex 或其他 CLI，切换后仍然回到原来的终端工作。

这点听上去平常，实际很省心。配置多了以后，最危险的不是多敲两行命令，而是你已经不知道哪份配置正在生效。统一入口至少让这件事变得可见。

## 哪些人值得装

如果你长期只用官方默认配置，没必要多加一层工具。只要你经常测试不同接口、在多个模型之间切换，或者需要给不同项目保留不同配置，cc-switch 就能明显减少手改文件的次数。

项目代码和最新发行版以 [cc-switch 官方项目页](https://github.com/farion1231/cc-switch) 为准。安装前先核对系统架构和版本，不要从来历不明的网盘下载安装包。

![cc-switch 官方项目页](/images/blog/cc-switch-introduction-install-guide/project.webp)

公开部分先帮你判断它值不值得装。各系统具体怎么下载、第一次如何添加供应商、切换后怎样确认 Claude Code 已读到新配置，完整步骤放在星球原帖。
