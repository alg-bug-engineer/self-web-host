## 统一制作规则

- 每节 8—12 分钟，一个具体问题、一个可观察实验、一个家庭任务。
- 当前公开试听为 4—9 分钟，必须保留核心判断动作和亲子任务；正式内测带领再结合分龄指南增加互动停顿、反馈与支架，不把试听播放计为课程开始或完成。
- 不把模型拟人化，不将生成结果包装成知识证明。
- 不出现真实儿童身份、学校、住址、正脸或私人聊天。
- 课程效果用作业过程、完成率和反馈验证，不使用生成画面暗示真实学员效果。
- NotebookLM 用于带来源的资料归纳和测验草案；即梦用于非真实人物视觉和短片头；最终脚本与事实由人工审核。
